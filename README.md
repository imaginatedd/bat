# Virtual Audio Cable

Приложение для создания виртуального аудиокабеля с обработкой микрофона в реальном времени без использования DAW.

## Возможности

- 🎙️ Захват звука с микрофона в реальном времени
- 🎚️ Полный набор аудио эффектов:
  - **Noise Gate** - подавление шума
  - **Compressor** - динамическая компрессия
  - **3-полосный EQ** - эквалайзер (Low/Mid/High)
  - **Reverb** - реверберация
  - **De-esser** - подавление сибилянтов
  - **Output Gain** - регулировка выходного уровня

- 🎨 Визуализация аудиосигнала в реальном времени
- 🎯 Готовые пресеты: Podcast, Gaming, Broadcast, Vocal Enhance, Clean Voice
- 🖥️ Удобный графический интерфейс

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Запустите приложение:
```bash
npm start
```

## Использование

1. Выберите устройство ввода (микрофон)
2. Нажмите "Start Processing"
3. Настройте эффекты или выберите готовый пресет
4. Звук с обработкой будет выводиться на системный аудиовыход

## VST3 плагины

Приложение умеет загружать настоящие VST3-плагины и менять их параметры.
Для этого нужен нативный хост, который собирается отдельно:

```powershell
cd native
cmake -S . -B build -DVST3_SDK_DIR=C:\path\to\vst3sdk
cmake --build build --config Release
```

Подробности — в `native/README.md`. После сборки хост будет лежать в
`native/build/Release/vst3_host.exe`, и кнопка "Load VST3 Plugin" заработает.

Пропускание аудио через сам плагин в реальном времени пока не подключено —
сейчас реализовано управление параметрами плагина.

## Технологии

- Electron - десктоп фреймворк
- Web Audio API - обработка аудио
- Vanilla JavaScript - без внешних зависимостей для аудио

## Системные требования

- Windows 10/11
- Микрофон или другое аудио устройство ввода
- Node.js 16+
